## What is independently licensed

The project's own website source has **no repository-wide software licence**. Publishing a repository does not itself grant visitors a reuse licence for its original source code. Third-party software retains its own terms. Plan Melbourne points, Transport Victoria timetable content and OSM-derived material also retain their respective source terms; no blanket licence is asserted over the combined `study.json` file.

The public snapshot is a container for independently sourced point, timetable and network information plus this project's calculated results. A licence notice for one component must not be read as relicensing a different component. See [public attribution](PUBLIC_ATTRIBUTION.md) for the intended visible wording.
