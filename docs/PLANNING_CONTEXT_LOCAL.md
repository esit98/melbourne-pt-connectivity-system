# Local Planning Context integration

20 October 2026. This page is developed only on local branch `codex/planning-prioritisation-local`. It has not been committed, pushed, deployed or added to the public V1 dashboard. The source is the frozen V2.1 static export plus a **separate experimental** JSON asset at `public/data/experimental/planning_context_v2.json` (SHA-256 `825475cc65bb34cf3980bc4575ae33ab7da6489c9872f8d679d9b43dbb6e8b73`). The page does not fetch OTP or PostGIS live.

The navigation entry is available for the V2.1 study only. The user can select a departure period and view (1) unweighted scheduled connectivity burden, (2) proxy demand context from 2021 SA2 origin residents and destination workplace employment, (3) 2021 SA2 equity context, or (4) transparent experimental combined profiles. Route buttons open the existing saved unweighted itinerary inspector. The normal overview, map, matrix and methods remain available. The UI labels the data as exploratory, explains the 2021/2026 mismatch, SA2/catchment limitation and lack of observed OD demand, and links to its source hashes.

The research repository owns data preparation and methodology: `scripts/prepare_v2_3_context.py`, `scripts/rank_v2_3_context.py`, `scripts/export_v2_3_planning.py`, `docs/V2_3_DEMAND_EQUITY_METHODOLOGY.md`, `system_development/data/SOURCE_REGISTER.md`. The exporter refuses to overwrite the JSON asset. A new source/routing version should create a new file and update the UI identity guard only after reviewed validation. The production release must separately confirm ABS/OSM attribution and the absence of unintended raw or private assets.

`npm.cmd test`: 29 passing tests after final edits. `npm.cmd run build`: passed. Durable logs are in the research package at `system_development/evidence/dashboard_tests_final.txt` and `dashboard_build_final.txt`.
